# 产业链景气度与企业分层 Evaluator 方案

## 1. 题目理解

本题不是单纯给产业链或企业打一个静态分数，而是要构建一套可解释、可追溯、可复核的评价器。评价对象分为两层：

1. 产业链层：判断某条产业链当前景气度、运行质量、风险状态。
2. 企业层：判断企业在该产业链中的位置和质量，将企业划分为核心层、骨干层、基础层、边缘层。

已有产业链表可以提供产业链结构信息，包括产业链 id、产业链名、节点代码、节点名称、节点层级、上中下游位置、节点分值、1-5 级节点路径。该表适合用来构建产业链树和产业链图谱，但不能直接等同于最终景气度评价。

核心思路：

```text
产业链表 -> 产业链结构图谱 -> 外部数据补全 -> 指标量化 -> 风险校验 -> Agent 修正 -> 输出评分、分层和证据链
```

## 2. 总体架构

建议做两个 evaluator：

```text
ChainEvaluator：产业链景气度评价器
EnterpriseEvaluator：链上企业分层评价器
```

两者关系：

```text
产业链节点景气度会影响企业评分；
企业经营质量和协同关系也会反向影响产业链景气度。
```

最终输出建议包含：

- 产业链综合景气度分数：0-100
- 景气等级：高景气、较高景气、平稳、承压、低迷
- 上中下游分项得分
- 关键驱动因素
- 主要断链风险
- 企业分层名单
- 每条结论的证据来源、时间戳和置信度

## 3. 产业链景气度指标体系

产业链评价建议使用 7 个一级指标，总分 100 分。

| 一级指标 | 权重 | 为什么重要 |
|---|---:|---|
| 供需匹配度 | 20 | 景气度首先来自真实需求和供给匹配，供不应求、库存下降、订单增长通常意味着景气改善 |
| 传导效率 | 15 | 衡量上游价格、产量、订单变化能否顺畅传导到中下游，传导慢说明链条堵塞或议价失衡 |
| 价值分配 | 15 | 衡量利润是否合理分布，若利润过度集中在某一环节，链条整体稳定性较差 |
| 企业协调度 | 15 | 衡量上下游企业协作、交易稳定性和产业链网络韧性 |
| 创新与政策支持 | 10 | 技术突破、专利、政策扶持会影响产业链中长期景气 |
| 实时市场景气 | 10 | 引入至少一个实时数据，捕捉市场预期和资金关注度 |
| 断链风险与合规韧性 | 15 | 风险是景气评价的底线项，供应集中、进口依赖、违法失信会显著压低评价 |

### 3.1 供需匹配度，20 分

评价内容：

- 下游销量、订单、出口、招投标需求是否增长
- 上游产能、产量、库存是否与需求匹配
- 中游企业产能利用率、开工率、交付周期是否健康

推荐量化：

```text
供需匹配度 = 0.4 * 需求增长分
          + 0.3 * 供给匹配分
          + 0.2 * 库存健康分
          + 0.1 * 订单/招投标活跃分
```

打分标准：

| 状态 | 分数 |
|---|---:|
| 需求同比明显增长，库存下降，供给缺口可控 | 85-100 |
| 需求增长，库存稳定，供给基本匹配 | 70-85 |
| 需求平稳，供给略有过剩或不足 | 55-70 |
| 需求下降，库存上升，产能过剩 | 35-55 |
| 需求明显萎缩，库存高企，价格承压 | 0-35 |

可用公式：

```text
需求增长分 = percentile(下游销量/订单/出口同比增速)

供给匹配分 = 100 - min(100, abs(供给增速 - 需求增速) * k)

库存健康分 = 100 - percentile(库存同比增速或库存周转天数)
```

### 3.2 传导效率，15 分

传导效率指上游、中游、下游之间价格、数量、利润变化的传递速度和顺畅程度。

例如：

```text
锂电材料价格变化 -> 电池成本/毛利率变化 -> eVTOL/无人机整机价格或利润变化
```

如果上游价格下降后，中游毛利率快速改善，说明成本传导顺畅；如果上游涨价但中游无法提价，说明中游被挤压，传导效率差。

推荐量化：

```text
传导效率 = 0.4 * 价格传导相关性分
        + 0.3 * 传导时滞分
        + 0.2 * 利润传导分
        + 0.1 * 数量传导分
```

计算方法：

1. 构造上游价格指数、中游毛利率/产品价格、下游销量或订单时间序列。
2. 做滞后相关分析，计算 0-6 个月不同滞后的相关系数。
3. 找到最大相关系数和对应滞后期。

```text
价格传导相关性分 = max_corr * 100

传导时滞分 = 100 * (1 - lag_months / 6)

利润传导分 = percentile(中游毛利率改善幅度)
```

打分标准：

| 状态 | 分数 |
|---|---:|
| 相关性 > 0.7，传导时滞 <= 1 个月 | 85-100 |
| 相关性 0.5-0.7，传导时滞 1-3 个月 | 70-85 |
| 相关性 0.3-0.5，传导时滞 3-6 个月 | 55-70 |
| 相关性弱或传导方向不稳定 | 35-55 |
| 无明显传导关系，利润被严重挤压 | 0-35 |

### 3.3 价值分配，15 分

价值分配看产业链利润是否过度集中，以及上中下游是否都能获得合理利润。

推荐量化：

```text
价值分配 = 0.5 * 全链条盈利能力分
        + 0.3 * 利润分布均衡分
        + 0.2 * 关键环节议价能力分
```

可用指标：

- 上游、中游、下游企业毛利率中位数
- 净利率中位数
- ROE、ROA
- 各环节利润占比
- 利润分布 HHI 或 Gini 系数

公式示例：

```text
利润分布 HHI = sum(各环节利润占比 ^ 2)

利润分布均衡分 = 100 * (1 - normalized_HHI)
```

注意：价值分配不是越平均越好。如果全链条都没有利润，虽然均衡，但不景气。因此必须同时看全链条盈利能力。

打分标准：

| 状态 | 分数 |
|---|---:|
| 全链条盈利改善，利润分布相对均衡 | 85-100 |
| 主要环节盈利较好，少数环节偏弱 | 70-85 |
| 总体盈利一般，利润集中度较高 | 55-70 |
| 多数环节利润承压，利润集中明显 | 35-55 |
| 全链条亏损或核心环节被严重挤压 | 0-35 |

### 3.4 企业协调度，15 分

企业协调度衡量产业链中企业之间是否形成稳定、有效的协同关系。

推荐量化：

```text
企业协调度 = 0.3 * 图谱连通性分
          + 0.25 * 交易稳定性分
          + 0.2 * 上下游覆盖分
          + 0.15 * 结算健康分
          + 0.1 * 协同事件分
```

可用指标：

- 企业供应链关系图的边密度、平均度数、连通分量数量
- 关键节点企业 PageRank / betweenness centrality
- 上中下游是否都有足够企业覆盖
- 资金流结算金额、结算频次、逾期情况
- 战略合作、联合研发、长期订单、框架协议

打分标准：

| 状态 | 分数 |
|---|---:|
| 上中下游连接充分，交易稳定，核心节点有替代 | 85-100 |
| 连接较完整，少数环节依赖核心企业 | 70-85 |
| 链条基本连通，但局部薄弱 | 55-70 |
| 关系稀疏，交易波动大，依赖单一节点 | 35-55 |
| 链条割裂，关键环节缺企业或交易异常 | 0-35 |

### 3.5 创新与政策支持，10 分

该指标衡量产业链的中长期成长动力。

推荐量化：

```text
创新与政策支持 = 0.35 * 专利活跃分
              + 0.25 * 研发投入分
              + 0.25 * 政策支持分
              + 0.15 * 融资/项目支持分
```

可用指标：

- 发明专利申请量、授权量、同比增速
- 企业研发费用率、研发人员占比
- 政府政策文件数量、政策级别、政策强度
- 专精特新、高新技术企业、重大项目、财政补贴
- 一级市场融资、产业基金投资

政策文本可由 Agent 提取：

```text
政策强度 = 政策级别权重 * 相关性 * 支持动作强度 * 时效衰减
```

其中：

- 国家级政策权重高于省市级政策
- 明确资金、试点、标准、采购、税收支持的政策权重更高
- 时间越新的政策权重越高

### 3.6 实时市场景气，10 分

该指标用于满足题目中至少一个实时数据的要求。推荐使用 A 股实时行情或行业指数实时行情。

实时数据来源：

- AKShare 的东方财富 A 股实时行情接口：`stock_zh_a_spot_em`
- AKShare 的沪 A、深 A 实时行情接口：`stock_sh_a_spot_em`、`stock_sz_a_spot_em`
- AKShare 的指数实时行情接口：`stock_zh_index_spot_em`

AKShare 文档说明这些接口可返回最新价、涨跌幅、成交量、成交额、换手率、市盈率、市净率、总市值等字段。

推荐量化：

```text
实时市场景气 = 0.4 * 链上企业实时涨跌强度
            + 0.3 * 成交活跃度
            + 0.2 * 相对大盘强度
            + 0.1 * 估值修复分
```

公式示例：

```text
链上企业实时涨跌强度 = 市值加权平均涨跌幅 percentile

成交活跃度 = 当日成交额 / 近 20 日平均成交额

相对大盘强度 = 链上企业市值加权涨跌幅 - 沪深300涨跌幅
```

打分标准：

| 状态 | 分数 |
|---|---:|
| 链上企业普涨，成交显著放大，强于大盘 | 85-100 |
| 多数上涨，成交活跃，略强于大盘 | 70-85 |
| 涨跌互现，成交正常 | 55-70 |
| 多数下跌，成交低迷 | 35-55 |
| 普跌、放量下跌或核心企业明显走弱 | 0-35 |

注意：实时市场数据噪声较大，所以权重不宜过高，建议 10%。

### 3.7 断链风险与合规韧性，15 分

断链风险是底线性指标，建议既作为一级指标，也作为强制扣分项。

推荐量化：

```text
断链韧性 = 0.25 * 供应集中度安全分
        + 0.2 * 进口依赖安全分
        + 0.2 * 关键节点冗余分
        + 0.15 * 财务风险安全分
        + 0.1 * 合规信用安全分
        + 0.1 * 舆情/政策风险安全分
```

风险扣分规则：

| 风险事件 | 处理方式 |
|---|---|
| 核心企业债务违约、重大违法、严重失信 | 产业链总分扣 5-15 分 |
| 关键节点只有 1-2 家企业且不可替代 | 断链韧性分最高不超过 60 |
| 单一供应商或客户占比超过 50% | 企业协调度和断链韧性同步扣分 |
| 高进口依赖且存在出口管制或地缘风险 | 断链韧性最高不超过 70 |
| 关键数据缺失严重 | 不强行高分，降低置信度 |

## 4. 产业链综合评分

总分公式：

```text
产业链景气度总分 =
  0.20 * 供需匹配度
+ 0.15 * 传导效率
+ 0.15 * 价值分配
+ 0.15 * 企业协调度
+ 0.10 * 创新与政策支持
+ 0.10 * 实时市场景气
+ 0.15 * 断链韧性
- 风险额外扣分
```

等级划分：

| 总分 | 等级 | 含义 |
|---:|---|---|
| 85-100 | 高景气 | 需求、利润、协同、资本预期均较强 |
| 70-85 | 较高景气 | 总体向好，局部存在压力 |
| 55-70 | 平稳 | 没有明显上行或下行趋势 |
| 40-55 | 承压 | 需求、利润或风险指标出现压力 |
| 0-40 | 低迷 | 多项指标恶化或存在重大风险 |

置信度：

```text
置信度 = 数据完整度 * 来源可信度 * 时间新鲜度 * 多源一致性
```

建议输出为：

```text
景气度分数：78.4
景气等级：较高景气
置信度：中高
主要驱动：下游订单增长、政策支持增强、链上企业市场表现较强
主要风险：上游关键材料供应集中、部分企业现金流承压
```

## 5. 企业分层评价指标体系

企业分层建议总分 100 分，重点不是企业大不大，而是企业在该产业链里是否关键、是否稳定、是否有替代难度。

| 一级指标 | 权重 | 为什么重要 |
|---|---:|---|
| 链上关键性 | 25 | 企业是否处于关键节点、是否影响链条运行，是分层最核心依据 |
| 经营基本面 | 20 | 财务质量决定企业能否持续承担链上角色 |
| 技术与资质壁垒 | 15 | 技术、专利、认证、牌照决定替代难度 |
| 协同与交易能力 | 15 | 真实交易、结算、供应关系比文本标签更可靠 |
| 成长与景气受益 | 10 | 企业是否受益于所在节点景气上行 |
| 风险与合规 | 15 | 重大风险会直接影响企业层级上限 |

### 5.1 链上关键性，25 分

推荐量化：

```text
链上关键性 = 0.35 * 节点重要度
          + 0.25 * 企业图谱中心性
          + 0.2 * 替代难度
          + 0.2 * 上下游覆盖能力
```

其中：

```text
节点重要度 = 产业链表中的节点分值 * 节点层级修正 * 上中下游位置修正
```

节点层级修正建议：

| 节点层级 | 修正逻辑 |
|---|---|
| 1-2 级 | 粒度较粗，适合判断赛道，不宜直接给企业高关键性 |
| 3 级 | 可作为细分赛道评价 |
| 4-5 级 | 更接近产品、材料、设备，企业映射更精确，权重更高 |

图谱中心性：

- PageRank：企业在供应链网络中的重要程度
- betweenness centrality：企业是否连接多个关键环节
- degree：上下游连接数量

### 5.2 经营基本面，20 分

上市公司：

- 营收规模、营收增速
- 净利润、扣非净利润
- 毛利率、净利率
- 经营现金流
- 资产负债率
- ROE

非上市企业：

- 注册资本、实缴资本
- 员工人数
- 纳税总额排名
- 社保人数
- 资金流结算金额
- 招投标中标金额
- 公开融资记录

建议处理方式：

```text
现金交易金额、纳税额、注册资本等长尾分布数据先做 log1p 处理；
员工人数可按企业规模国家标准或行业分位数分箱；
同一指标优先在同产业链、同节点内做分位数归一化。
```

### 5.3 技术与资质壁垒，15 分

推荐量化：

```text
技术与资质壁垒 = 0.35 * 发明专利质量
              + 0.25 * 研发投入强度
              + 0.2 * 行业认证/牌照
              + 0.2 * 产品或工艺稀缺性
```

适合低空经济的资质示例：

- 无人机、eVTOL、通航相关适航、试飞、运营资质
- 高新技术企业、专精特新、小巨人
- 军工资质、民航相关认证
- 核心专利、标准参与、检测认证

### 5.4 协同与交易能力，15 分

推荐量化：

```text
协同与交易能力 = 0.35 * 交易规模分
              + 0.25 * 交易稳定性分
              + 0.2 * 客户/供应商质量分
              + 0.2 * 结算健康分
```

已有资金流结算数据很重要，可作为区别于普通公开信息方案的亮点。

处理建议：

- 交易金额做 log1p
- 交易频次看连续性
- 客户/供应商数量看多样性
- 应收应付和逾期看结算健康
- 单一客户/供应商过高则扣风险分

### 5.5 成长与景气受益，10 分

企业是否能享受所在节点景气度。

```text
成长与景气受益 = 0.4 * 所属节点景气度
              + 0.25 * 企业收入/订单增长
              + 0.2 * 产能扩张或新项目
              + 0.15 * 资本市场/融资热度
```

### 5.6 风险与合规，15 分

推荐量化：

```text
风险与合规 = 0.25 * 财务安全分
          + 0.25 * 司法信用安全分
          + 0.2 * 经营稳定分
          + 0.15 * 舆情安全分
          + 0.15 * 监管处罚安全分
```

强制规则：

| 情况 | 分层限制 |
|---|---|
| 严重违法失信、债务违约、重大被执行 | 不得评为核心层 |
| 数据缺失严重且无法交叉验证 | 不得评为核心层，置信度标低 |
| 单一客户/供应商高度依赖 | 层级最高限制为骨干层 |
| 负面舆情未被权威来源证实 | 不直接定性，只作为风险提示 |

## 6. 企业分层标准

基础分层：

| 企业总分 | 层级 | 解释 |
|---:|---|---|
| 85-100 | 核心层 | 处于关键节点，技术/市场/交易影响力强，替代难度高，风险可控 |
| 70-85 | 骨干层 | 规模和能力较强，对产业链有稳定支撑，但控制力弱于核心层 |
| 55-70 | 基础层 | 承担常规供给、配套、制造或服务能力，重要性中等 |
| 0-55 | 边缘层 | 关联弱、规模小、替代性强、数据不足或风险较高 |

建议增加门槛条件，避免只靠总分误判：

```text
核心层：总分 >= 85，链上关键性 >= 80，风险与合规 >= 65
骨干层：总分 >= 70，链上关键性 >= 60，风险与合规 >= 55
基础层：总分 >= 55，且至少能映射到明确产业链节点
边缘层：总分 < 55，或产业链关联证据弱
```

数据来源可靠性建议：

```text

```

研报和新闻适合做辅助解释，不宜作为唯一评分依据。

## 8. Multi-Agent 方案

建议设计 8 类 Agent。

```text
Planner Agent
  负责拆解任务，确定产业链、节点、企业、数据需求。

Chain Graph Agent
  读取产业链表，构建 1-5 级节点树和上中下游图谱。

Data Collector Agent
  抓取公告、行情、统计、政策、专利、招投标、司法风险数据。

Entity Linking Agent
  负责企业名称、简称、股票代码、统一社会信用代码、子公司、产品名对齐。

Indicator Agent
  把原始数据转换为标准化指标，例如增长率、分位数、HHI、中心性。

Scoring Agent
  根据规则和权重计算产业链分数、节点分数、企业分数。

Risk & Compliance Agent
  专门检查断链风险、违法失信、数据缺失、来源过期、敏感结论。

Report Agent
  生成最终报告，输出结论、证据链、置信度和风险提示。
```

多 Agent 协作流程：

```text
输入产业链表和企业表
        |
Planner Agent 拆任务
        |
Chain Graph Agent 构建产业链图谱
        |
Data Collector Agent 拉取外部数据
        |
Entity Linking Agent 做实体对齐
        |
Indicator Agent 指标结构化
        |
Scoring Agent 规则化评分
        |
Risk & Compliance Agent 做底线校验
        |
Report Agent 输出报告
```

Agent 修正机制：

```text
基础分 = 规则化量化评分
修正分 = Agent 基于政策、研报、公告提取的增减分
最终分 = 基础分 + 修正分 - 风险扣分
```

修正分建议限制在较小范围：

```text
政策明确支持：+0 到 +5
重大订单/重大项目：+0 到 +5
重大负面事件：-5 到 -15
数据无法验证：不加分，只降低置信度
```

## 9. 可靠性与底线性设计

必须遵守以下原则：

1. 不编造数据。没有来源的数据不能进入最终评分。
2. 所有关键结论保留来源链接、发布时间、抓取时间。
3. 重要结论至少两类来源交叉验证，例如公告 + 行情，政策 + 招投标。
4. 外部文本只做证据，不直接当事实，尤其是研报和新闻。
5. 实时行情只反映市场预期，不等同于真实经营改善。
6. 非上市企业财务缺失时，用替代指标，但必须降低置信度。
7. 对缺失值不简单填高分，可用行业中位数填补并标注低置信度。
8. 重大违法失信、债务违约、严重处罚触发层级上限。
9. 输出中避免投资建议式表达，只做产业评价和企业画像。
10. 对低置信度结论必须明确标注，不强行给确定性判断。

## 10. 推荐 MVP 落地路径

第一阶段，先做可跑通的规则 evaluator：

1. 读取产业链节点表，构建产业链树。
2. 读取企业表，将企业映射到节点。
3. 使用已有企业画像、资金流结算、纳税、员工、注册地等数据。
4. 接入一个实时行情数据源，先覆盖上市公司。
5. 接入公告/年报或研报文本，做政策和行业趋势辅助。
6. 输出产业链总分、节点得分、企业分层。

第二阶段，增强外部数据：

1. 加入专利、招投标、海关、国家统计局数据。
2. 加入供应链图谱中心性和断链风险模型。
3. 加入 Agent 证据抽取和反驳校验。
4. 加入评分解释和置信度。

第三阶段，做动态监控：

1. 每日更新实时行情。
2. 每周更新新闻、政策、研报、招投标。
3. 每月更新宏观、行业、海关数据。
4. 每季更新财报和主营构成。

## 11. 可作为比赛亮点的创新点

1. 产业链图谱化：利用 1-5 级节点和上中下游字段构建产业链网络。
2. 量化评分 + Agent 修正：基础分来自规则，文本信息只做有限修正。
3. 实时数据引入：用实时行情捕捉市场对产业链的边际预期。
4. 断链风险前置：把供应集中、进口依赖、违法失信作为底线项。
5. 非上市企业适配：使用纳税、员工、结算、招投标、专利替代财务数据。
6. 证据链评分：每个分数绑定数据来源、时间戳、置信度。
7. 反驳式校验：Risk & Compliance Agent 专门审查过度结论和数据幻觉。
