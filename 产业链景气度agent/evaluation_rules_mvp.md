# 产业链景气度 MVP 评价指标与规则

本阶段只评价五条产业链的景气度，不做企业分层：

- 半导体产业链
- 低空经济产业链
- 机器人产业链
- 生物医药产业链
- 新能源汽车产业链

## 1. 指标体系

MVP 版本使用 5 个一级指标，总分 100 分。

| 指标                 | 权重 | 重要程度 | 数据来源                      | 是否实时  |
| -------------------- | ---: | -------- | ----------------------------- | --------- |
| 宏观与行业景气       |   35 | 最高     | 国家统计局预爬数据            | 否        |
| 政策支持与限制       |   25 | 高       | 发改委、工信部政策文件预爬    | 否        |
| 上中下游结构敏感性   |   20 | 高       | 产业链节点表                  | 否        |
| 实时市场景气         |   10 | 中       | 东方财富概念/行业板块实时行情 | 是        |
| 数据可靠性与风险底线 |   10 | 中高     | 数据完整度、来源、风险事件    | 否/准实时 |

总分公式：

```text
产业链景气度总分 =
  0.35 * 宏观与行业景气
+ 0.25 * 政策支持与限制
+ 0.20 * 上中下游结构敏感性
+ 0.10 * 实时市场景气
+ 0.10 * 数据可靠性与风险底线
- 重大风险扣分
```

等级规则：

|   总分 | 等级     | 解释                                       |
| -----: | -------- | ------------------------------------------ |
| 85-100 | 高景气   | 宏观、政策、结构和市场信号都较强，风险可控 |
|  70-85 | 较高景气 | 总体向好，但局部存在压力或数据滞后         |
|  55-70 | 平稳     | 没有明显上行或下行，结构性机会为主         |
|  40-55 | 承压     | 需求、政策、市场或风险指标出现压力         |
|   0-40 | 低迷     | 多项指标恶化，或存在重大风险               |

## 2. 指标选择理由

### 2.1 宏观与行业景气，35 分

为什么重要：

产业链景气度首先要落到真实经济活动上。国家统计局的 GDP、PMI、PPI、工业产量、工业企业利润、库存等数据，能够判断行业所处的大周期方向。

适合回答：

```text
行业是在扩张还是收缩？
需求有没有改善？
上游价格和成本压力是否明显？
企业利润和库存是否健康？
```

打分方法：

```text
宏观与行业景气 =
  0.35 * 产量/需求同比分
+ 0.25 * 利润改善分
+ 0.20 * 库存健康分
+ 0.20 * 宏观环境分
```

简化实现：

- 如果预爬数据里已经有 `score` 字段，直接使用。
- 如果只有 `yoy`，用同比增速转换成 0-100 分。
- 正向指标如产量、利润、PMI，新高更好。
- 逆向指标如库存、成本压力，需要反向计分。

### 2.2 政策支持与限制，25 分

为什么重要：

五条产业链都强依赖政策环境。低空经济、新能源汽车、半导体、机器人、生物医药都有明显的产业政策、准入监管、标准制定和财政支持影响。

适合回答：

```text
政策是在鼓励还是限制？
是否有试点、补贴、专项行动、基础设施建设？
是否存在准入收紧、安全监管、集采降价等压力？
```

打分方法：

```text
政策支持分 = 支持政策强度 - 限制政策强度 + 中性政策覆盖度
```

政策强度：

| 政策类型                       | 强度 |
| ------------------------------ | ---: |
| 国家级规划、重大专项、强制标准 |    5 |
| 部委正式通知、试点、资金支持   |    4 |
| 行业指导意见、专项行动         |    3 |
| 地方政策、园区政策             |    2 |
| 一般新闻、解读、会议           |    1 |

时间衰减：

```text
最近 180 天：100% 权重
180-365 天：70% 权重
1-2 年：40% 权重
超过 2 年：20% 权重
```

### 2.3 上中下游结构敏感性，20 分

为什么重要：

产业链不是一个单点行业，而是由上游、中游、下游节点构成。相同的宏观变量对不同环节影响不同，例如 PPI 上行可能利好上游资源，但压制中游制造利润。

适合回答：

```text
这条产业链哪个环节最敏感？
上游、中游、下游是否均衡？
产业链表里的高分节点集中在哪里？
```

打分方法：

```text
结构敏感性 =
  0.60 * 节点平均重要度
+ 0.25 * 上中下游覆盖均衡度
+ 0.15 * 高分关键节点占比
```

节点平均重要度优先使用产业链表里的 `分值` 字段。

### 2.4 实时市场景气，10 分

为什么重要：

题目要求至少有一个实时数据。实时行情能捕捉市场对产业链边际变化的即时反应，但噪声大，所以权重只给 10%。

本阶段只用一个实时源：

```text
东方财富概念/行业板块实时行情，使用 AKShare 封装。
```

不用全 A 股关键词检索的原因：

```text
关键词检索噪声大，容易混入蹭概念公司；
产业链涉及多个板块，先用板块聚合更稳定；
MVP 阶段更需要可解释和可复核。
```

打分方法：

```text
实时市场景气 =
  0.50 * 板块涨跌幅分
+ 0.30 * 上涨扩散度分
+ 0.20 * 成交活跃度分
```

### 2.5 数据可靠性与风险底线，10 分

为什么重要：

景气度评价不能只追求高分，必须处理底线问题。数据缺失、来源不可靠、重大负面政策、监管处罚、供应链断点都会影响结果可信度。

打分方法：

```text
可靠性分 =
  0.40 * 数据完整度
+ 0.30 * 来源可信度
+ 0.20 * 时间新鲜度
+ 0.10 * 多源一致性
```

底线规则：

| 情况                              | 处理                                 |
| --------------------------------- | ------------------------------------ |
| 核心数据缺失严重                  | 总分不高于 70，置信度降低            |
| 只有新闻或研报，没有官方/公告数据 | 不允许强利好结论                     |
| 出现明确限制政策                  | 政策分扣分                           |
| 出现重大风险事件                  | 总分额外扣 5-15 分                   |
| 实时数据缺失                      | 实时市场分按中性处理，不影响程序运行 |

## 3. 两个 Agent 是否重复

如果把“Data Agent”定义成“理解任务后调用工具”，它确实会和主控 `orchestrator.py` 重复。

因此 MVP 建议只保留两个 Agent：

| Agent                  | 职责                                       |
| ---------------------- | ------------------------------------------ |
| Interpretation Agent   | 理解自然语言，识别产业链、关键词、板块候选 |
| Scoring & Report Agent | 根据工具返回的数据打分、解释、输出报告     |

工具调用链由 `orchestrator.py` 直接负责：

```text
用户问题
  -> Interpretation Agent
  -> orchestrator.py 调用离线数据工具和实时行情工具
  -> Scoring & Report Agent
  -> 输出报告
```

这样分工更清楚：Agent 做“理解和判断”，Tool 做“确定性数据调用”，Orchestrator 做“流程控制”。
