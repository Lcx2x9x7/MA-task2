# 五条产业链景气度 Evaluator 方案

适用产业链：

| 产业链           | 产业链 ID |
| ---------------- | --------: |
| 半导体产业链     |     78492 |
| 低空经济产业链   |      1921 |
| 机器人产业链     |    119013 |
| 生物医药产业链   |     36112 |
| 新能源汽车产业链 |     70258 |

本阶段只评价“产业链景气度”，不做企业核心层、骨干层、基础层、边缘层分层。

## 1. 总体思路

景气度评价不要只看新闻热度，也不要只看股价。建议把产业链景气度拆成三类信号：

1. 基本面信号：需求、产量、价格、利润、库存、进出口。
2. 结构信号：上中下游传导、价值分配、企业协同、断链风险。
3. 边际信号：实时行情、商品期货、政策、招投标、审批、专利。

最终输出：

```text
产业链景气度总分：0-100
景气等级：高景气 / 较高景气 / 平稳 / 承压 / 低迷
上游、中游、下游分项分数
主要驱动因素
主要拖累因素
断链风险提示
数据置信度
证据来源
```

## 2. 指标体系与权重

建议使用 7 个一级指标，总分 100 分。

| 一级指标       | 权重 | 核心问题                                       | 是否需要实时数据             |
| -------------- | ---: | ---------------------------------------------- | ---------------------------- |
| 供需匹配度     |   25 | 需求是否增长，供给是否匹配，有没有库存压力     | 否，主要月度/季度            |
| 传导效率       |   15 | 上游价格、产量、订单是否顺畅传导到中下游       | 部分实时，上游商品价格可实时 |
| 价值分配       |   12 | 利润是否合理分布，是否某一环节过度挤压其他环节 | 否，主要季度/年度            |
| 企业协调度     |   13 | 链上企业连接是否稳定，交易和合作是否活跃       | 部分准实时，公告/订单可日更  |
| 技术与政策催化 |   10 | 政策、专利、审批、技术突破是否带来中长期景气   | 否，日更/月更                |
| 实时市场景气   |   10 | 资本市场和商品市场是否正在反映边际改善         | 是，核心实时指标             |
| 断链风险与韧性 |   15 | 是否有供应集中、进口依赖、合规、安全、地缘风险 | 部分准实时，风险事件日更     |

总分公式：

```text
景气度总分 =
  0.25 * 供需匹配度
+ 0.15 * 传导效率
+ 0.12 * 价值分配
+ 0.13 * 企业协调度
+ 0.10 * 技术与政策催化
+ 0.10 * 实时市场景气
+ 0.15 * 断链韧性
- 重大风险扣分
```

等级标准：

|   总分 | 等级     | 解读                                         |
| -----: | -------- | -------------------------------------------- |
| 85-100 | 高景气   | 需求、利润、政策、市场预期同时较强，风险可控 |
|  70-85 | 较高景气 | 总体向好，但存在局部供需、利润或风险压力     |
|  55-70 | 平稳     | 景气无明显上行或下行，结构性机会为主         |
|  40-55 | 承压     | 需求、价格、利润或风险指标明显走弱           |
|   0-40 | 低迷     | 多项指标恶化，或存在重大断链/合规风险        |

## 3. 各指标如何获取

### 3.1 供需匹配度，25 分

作用：

供需匹配是景气度最核心的基础。如果需求增长、库存下降、产量和订单跟得上，说明产业链真实景气；如果只是新闻热，但产销和订单没有改善，分数不能高。

数据获取：

| 数据                                                   | 获取方式                                             | 更新频率  | 适用产业链                                     |
| ------------------------------------------------------ | ---------------------------------------------------- | --------- | ---------------------------------------------- |
| 国家统计局工业产品产量，如集成电路、工业机器人、汽车等 | 国家数据网页/API 抓取，按关键词匹配指标              | 月度      | 半导体、机器人、新能源汽车                     |
| 规模以上工业企业收入、成本、利润、库存、应收账款       | 国家统计局月度工业企业利润数据，按行业提取           | 月度      | 五条产业链均可映射到相关行业                   |
| 进出口数量和金额                                       | 海关总署统计，按 HS 编码抓取                         | 月度      | 半导体、新能源汽车、生物医药、机器人、低空经济 |
| 新能源汽车产销                                         | 中国汽车工业协会、工信部、国家统计局                 | 月度      | 新能源汽车                                     |
| 通航、无人机、低空飞行数据                             | 民航局统计公报、月度主要生产指标、地方低空政策和项目 | 月度/年度 | 低空经济                                       |
| 药品、医疗器械审批和临床试验                           | NMPA、CDE、药物临床试验登记平台                      | 日更/周更 | 生物医药                                       |
| 招投标、中标项目                                       | 政府采购网、公共资源交易平台，关键词爬取             | 日更/周更 | 五条产业链                                     |

量化方法：

```text
需求增长分 = 相关需求指标同比增速的分位数
供给匹配分 = 100 - abs(供给增速 - 需求增速) * 惩罚系数
库存健康分 = 100 - 库存同比增速分位数
订单活跃分 = 招投标/中标金额同比增速分位数

供需匹配度 =
  0.40 * 需求增长分
+ 0.25 * 供给匹配分
+ 0.20 * 库存健康分
+ 0.15 * 订单活跃分
```

打分标准：

| 状态                                 |   分数 |
| ------------------------------------ | -----: |
| 需求同比明显增长，供给匹配，库存下降 | 85-100 |
| 需求增长，库存稳定，供需基本平衡     |  70-85 |
| 需求平稳，局部供给过剩或不足         |  55-70 |
| 需求下降，库存上升，产能利用偏弱     |  35-55 |
| 需求明显萎缩，库存高企，订单减少     |   0-35 |

### 3.2 传导效率，15 分

作用：

传导效率衡量上游变化是否能传导到中下游。景气链条不是孤立的，如果上游价格下跌但中游毛利没有改善，或者下游需求增长没有带动中游订单，说明链条传导不顺。

典型例子：

```text
新能源汽车：
锂价变化 -> 电池企业毛利率 -> 整车价格/销量

半导体：
晶圆/设备/材料供给 -> 芯片产量 -> 电子终端需求

机器人：
减速器/伺服/控制器成本 -> 整机价格 -> 制造业投资需求
```

数据获取：

| 数据                                       | 获取方式                                                    |    更新频率 | 是否实时   |
| ------------------------------------------ | ----------------------------------------------------------- | ----------: | ---------- |
| 商品期货价格，如碳酸锂、铜、铝、镍、工业硅 | AKShare 期货实时接口或交易所行情                            | 分钟级/日频 | 是         |
| 上游材料现货价格                           | 生意社、SMM、百川等公开页面；若无授权，只保留可公开抓取字段 |   日频/周频 | 部分准实时 |
| 中游产品价格                               | 行业网站、研报、公告、招投标单价                            |   周频/月频 | 否         |
| 下游销量/订单                              | 国家统计局、行业协会、招投标、公告                          |   月度/日更 | 否         |
| 上中下游毛利率                             | 上市公司财报、东方财富/巨潮年报                             |        季度 | 否         |

量化方法：

```text
1. 构建上游价格指数 P_up
2. 构建中游盈利/价格指数 M_mid
3. 构建下游需求指数 D_down
4. 计算 0-6 个月滞后相关性

价格传导分 = max_corr(P_up, M_mid) * 100
需求传导分 = max_corr(D_down, M_mid) * 100
时滞分 = 100 * (1 - 最优滞后月数 / 6)

传导效率 =
  0.40 * 价格传导分
+ 0.35 * 需求传导分
+ 0.25 * 时滞分
```

打分标准：

| 状态                                  |   分数 |
| ------------------------------------- | -----: |
| 上中下游相关性强，传导滞后小于 1 个月 | 85-100 |
| 相关性较强，传导滞后 1-3 个月         |  70-85 |
| 相关性一般，传导滞后 3-6 个月         |  55-70 |
| 传导弱，部分环节利润被挤压            |  35-55 |
| 传导失效，链条明显堵塞                |   0-35 |

### 3.3 价值分配，12 分

作用：

价值分配看利润是不是集中在某一段。如果上游拿走大部分利润，中游和下游长期亏损，这条链虽然可能有热度，但整体健康度不高。

数据获取：

| 数据                                  | 获取方式                                        | 更新频率 |
| ------------------------------------- | ----------------------------------------------- | -------: |
| 链上上市公司营收、毛利率、净利率、ROE | 财报、巨潮资讯、交易所公告、东方财富财务接口    |     季度 |
| 国家统计局分行业收入、成本、利润      | 国家统计局工业企业利润数据                      |     月度 |
| 上中下游企业篮子                      | 产业链表节点 + 企业映射表 + 行业/概念板块成份股 | 月度校准 |

量化方法：

```text
全链盈利分 = 上中下游毛利率/净利率的加权分位数
利润均衡分 = 100 * (1 - 归一化利润 HHI)
弱环节惩罚 = min(上游分, 中游分, 下游分)

价值分配 =
  0.45 * 全链盈利分
+ 0.35 * 利润均衡分
+ 0.20 * 弱环节惩罚
```

注意：

利润不是越平均越好。若所有环节都低利润，不能高分。因此必须同时看“全链盈利分”和“利润均衡分”。

### 3.4 企业协调度，13 分

作用：

企业协调度衡量链条是否能稳定协作。即使需求不错，如果供应链关系松散、核心节点缺失、交易不稳定，也会影响景气度。

数据获取：

| 数据                       | 获取方式                                           |  更新频率 |
| -------------------------- | -------------------------------------------------- | --------: |
| 产业链节点关系             | 已有产业链表，利用 1-5 级节点路径建树              | 静态/低频 |
| 企业-节点映射              | 已有企业供应链位置数据；用企业主营、公告、官网补充 |      月度 |
| 交易/资金流结算            | 你已有的企业资金流结算数据                         | 日频/月频 |
| 上下游合作、订单、框架协议 | 公告、新闻、招投标、研报，LLM 结构化抽取           | 日更/周更 |

量化方法：

```text
图谱连通性分 = 产业链图中最大连通子图占比
节点覆盖分 = 有企业覆盖的关键节点数 / 全部关键节点数
交易稳定分 = 连续交易月份数、交易金额稳定性、结算健康度
协同事件分 = 战略合作、长期订单、联合研发、产业联盟事件得分

企业协调度 =
  0.30 * 图谱连通性分
+ 0.25 * 节点覆盖分
+ 0.25 * 交易稳定分
+ 0.20 * 协同事件分
```

### 3.5 技术与政策催化，10 分

作用：

产业链景气不仅来自当期产销，也来自政策、技术、审批、专利带来的未来预期。

数据获取：

| 数据                             | 获取方式                                                       |    更新频率 | 适用产业链                 |
| -------------------------------- | -------------------------------------------------------------- | ----------: | -------------------------- |
| 国家和地方政策                   | 中国政府网政策库、工信部、发改委、民航局、药监局、地方政府网站 |   日更/周更 | 五条                       |
| 专利数量和质量                   | 国家知识产权局专利检索及分析系统、重点产业专利信息服务平台     |   月度/季度 | 五条                       |
| 药品和医疗器械审批               | NMPA、CDE、临床试验登记平台                                    |   日更/周更 | 生物医药                   |
| 低空经济试点、空域、基础设施政策 | 民航局、地方政府、公共资源交易平台                             |   日更/周更 | 低空经济                   |
| 工信部行业运行数据               | 工信部运行监测协调局                                           | 月度/不定期 | 半导体、新能源汽车、机器人 |

政策文本抽取字段：

```json
{
  "policy_title": "",
  "publish_date": "",
  "publisher_level": "国家级/部委/省级/市级",
  "related_chain": "",
  "related_node": "",
  "support_type": "资金/税收/试点/采购/标准/准入/监管",
  "direction": "利好/中性/利空",
  "strength": 1,
  "evidence": "",
  "source_url": ""
}
```

量化方法：

```text
政策分 = sum(政策级别权重 * 支持类型权重 * 相关性 * 时间衰减)
专利分 = 发明专利申请/授权数量、同比增速、核心申请人集中度
技术事件分 = 重大审批、适航进展、临床进展、技术突破事件得分

技术与政策催化 =
  0.40 * 政策分
+ 0.35 * 专利分
+ 0.25 * 技术事件分
```

### 3.6 实时市场景气，10 分

作用：

这是本方案明确引入的实时数据。它不代表真实经营结果，但能反映资金对产业链边际变化的定价。

实时数据来源：

| 实时数据             | 获取方式                                                                  | 说明                                                                  |
| -------------------- | ------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| A 股实时行情         | AKShare`stock_zh_a_spot_em`                                             | 获取全 A 股票最新价、涨跌幅、成交额、换手率、市盈率、市净率、总市值等 |
| 东方财富概念板块行情 | AKShare`stock_board_concept_name_em`、`stock_board_concept_cons_em`   | 获取半导体、低空经济、机器人、新能源汽车、生物医药等概念板块及成份股  |
| 东方财富行业板块行情 | AKShare`stock_board_industry_name_em`、`stock_board_industry_cons_em` | 获取半导体、自动化设备、生物制品、汽车零部件、电池等行业板块          |
| A 股指数实时行情     | AKShare`stock_zh_index_spot_em`                                         | 用沪深 300、创业板指等作为相对收益基准                                |
| 国内期货实时行情     | AKShare`futures_zh_realtime` 或 `futures_zh_spot`                     | 用碳酸锂、铜、铝、镍、工业硅等跟踪上游成本和材料景气                  |

实时评分方法：

```text
链上股票篮子 = 产业链相关上市公司，按节点重要度和市值加权

实时股票强度 = 链上股票篮子市值加权涨跌幅 - 沪深300涨跌幅
成交活跃度 = 链上股票篮子成交额 / 近 20 日平均成交额
上涨扩散度 = 上涨股票数量 / 链上股票数量
期货景气信号 = 相关商品主力合约涨跌幅，按方向修正

实时市场景气 =
  0.35 * 实时股票强度
+ 0.25 * 成交活跃度
+ 0.20 * 上涨扩散度
+ 0.20 * 期货景气信号
```

期货方向要按产业链解释，不是所有商品涨价都是利好：

```text
新能源汽车：
碳酸锂上涨可能利好上游锂资源，但可能压制电池和整车利润。

机器人：
铜、铝、钢材上涨可能抬升成本，对中游整机未必是利好。

半导体：
工业硅、贵金属、电子化学品价格变化要结合下游需求判断。
```

建议实时数据权重只给 10%，避免短期市场波动主导景气判断。

### 3.7 断链风险与韧性，15 分

作用：

断链风险是底线指标。即使需求和市场很热，只要存在关键节点高度依赖、进口受限、合规处罚、供应中断，就不能给高景气。

数据获取：

| 数据               | 获取方式                                           |  更新频率 |
| ------------------ | -------------------------------------------------- | --------: |
| 关键节点企业数量   | 产业链表 + 企业映射表                              |      月度 |
| 供应集中度         | 企业客户/供应商、交易结算、年报前五大客户供应商    | 季度/年度 |
| 进口依赖度         | 海关总署，按 HS 编码看进口数量、金额、来源国集中度 |      月度 |
| 监管处罚/失信/诉讼 | 证监会、交易所、信用中国、法院执行信息公开网       | 日更/周更 |
| 地缘和出口管制风险 | 官方公告、商务部、海关、海外监管机构公开信息       |  事件驱动 |

量化方法：

```text
供应集中安全分 = 100 - 供应商/来源国集中度分位数
关键节点冗余分 = min(100, 关键节点企业数 / 目标企业数 * 100)
进口依赖安全分 = 100 - 进口依赖度分位数
合规安全分 = 100 - 处罚/失信/诉讼风险扣分

断链韧性 =
  0.30 * 供应集中安全分
+ 0.25 * 关键节点冗余分
+ 0.25 * 进口依赖安全分
+ 0.20 * 合规安全分
```

强制底线规则：

| 情况                                       | 处理                         |
| ------------------------------------------ | ---------------------------- |
| 关键节点只有 1-2 家企业且无替代            | 断链韧性最高 60              |
| 核心原料或设备高度进口依赖，且存在管制风险 | 总分最高 75                  |
| 链上核心企业出现重大违法、退市、债务违约   | 总分扣 5-15                  |
| 数据缺失严重                               | 不强行高分，降低置信度       |
| 只有研报或新闻支持，没有官方/公告数据      | 只作为解释，不作为强评分依据 |

## 4. 五条产业链的数据抓取重点

### 4.1 半导体产业链

关键词：

```text
半导体、集成电路、芯片、晶圆、封装测试、半导体设备、半导体材料、光刻胶、EDA、功率半导体
```

主要抓取：

| 维度     | 数据                                                   | 来源/方式                                | 实时性    |
| -------- | ------------------------------------------------------ | ---------------------------------------- | --------- |

## 5. 哪些数据算实时

## 6. Multi-Agent 设计

建议不是一个 Agent 直接打分，而是多个 Agent 分工。

### 6.1 Agent 列表

| Agent                     | 作用                                                 | 输入                            | 输出                         |
| ------------------------- | ---------------------------------------------------- | ------------------------------- | ---------------------------- |
| Planner Agent             | 决定本次评价哪些产业链、哪些节点、哪些关键词和数据源 | 五条产业链 ID、产业链表         | 抓取计划、关键词、数据源清单 |
| Chain Structure Agent     | 解析产业链表，构建 1-5 级节点树和上中下游结构        | 产业链节点表                    | 产业链图谱、上中下游节点集合 |
| Supply-Demand Agent       | 抓取产量、销量、订单、进出口、库存                   | 统计局、海关、协会、招投标      | 供需匹配度指标               |
| Price Transmission Agent  | 抓取商品价格、期货、产品价格、毛利率，计算传导效率   | 期货行情、财报、产品价格        | 传导效率指标                 |
| Value Distribution Agent  | 计算上中下游利润和价值分配                           | 财报、行业利润、企业篮子        | 价值分配指标                 |
| Coordination Agent        | 计算节点覆盖、交易稳定、合作事件                     | 产业链图谱、资金流、公告        | 企业协调度指标               |
| Policy & Innovation Agent | 抓政策、专利、审批、技术事件                         | 政策库、CNIPA、NMPA/CDE、工信部 | 政策技术催化指标             |
| Realtime Market Agent     | 抓实时股票、板块、指数、期货行情                     | AKShare                         | 实时市场景气指标             |
| Risk Agent                | 检查断链、进口依赖、处罚、失信、重大负面             | 海关、公告、信用平台            | 断链韧性分、风险扣分         |
| Scoring Agent             | 统一归一化、加权、扣分、分级                         | 所有指标                        | 产业链景气度总分             |
| Verifier Agent            | 校验来源、时间戳、缺失值、过度结论                   | 评分结果和证据                  | 置信度、修正建议             |
| Report Agent              | 生成最终报告                                         | 分数、证据、风险                | 景气度报告                   |

### 6.2 Agent 工作流

```text
产业链表 + 五条产业链 ID
        |
Planner Agent
        |
Chain Structure Agent
        |
并行执行：
  Supply-Demand Agent
  Price Transmission Agent
  Value Distribution Agent
  Coordination Agent
  Policy & Innovation Agent
  Realtime Market Agent
  Risk Agent
        |
Scoring Agent
        |
Verifier Agent
        |
Report Agent
```

## 7. 数据归一化与缺失值处理

不同产业链指标不能直接用绝对值比较，要做同口径归一化。

推荐方法：

```text
同比增速类：按过去 24-36 个月历史分位数打分
价格类：按近 12 个月涨跌幅、波动率、趋势方向打分
财务类：按同产业链、同环节公司分位数打分
政策类：按政策级别、支持动作、相关性、时间衰减打分
事件类：按事件强度 + 来源可信度 + 时间衰减打分
风险类：按风险等级扣分或设置总分上限
```

缺失值处理：

| 情况                 | 处理方式                                     |
| -------------------- | -------------------------------------------- |
| 单一指标缺失         | 用同产业链同环节中位数填补，并降低置信度     |
| 一级指标缺失超过 50% | 该一级指标不给高于 60 分                     |
| 缺少官方或公告证据   | 只允许中性评分，不允许强利好                 |
| 仅有研报观点         | 可作为解释，不直接作为主评分                 |
| 实时数据缺失         | 实时市场景气用最近交易日收盘数据替代，并标注 |

## 8. 可靠性与底线规则

1. 不编造数据，不把 LLM 推断当作事实。
2. 每个指标必须有数据来源、发布时间、抓取时间。
3. 官方数据和公告优先，研报和新闻只做辅助。
4. 实时行情权重不超过 10%，避免短期波动主导结论。
5. 风险事件要单独触发扣分或评级上限。
6. 政策热度不能直接等同于产业景气。
7. 数据缺失时降低置信度，不强行高分。
8. 对不同产业链使用不同关键词和指标口径，不能一个模板硬套。
9. 输出“产业评价”，避免写成投资建议。
10. 最终报告要区分“事实数据”“模型推断”“Agent 文本判断”。

## 9. 推荐 MVP

第一版先跑通以下最小闭环：

1. 读取产业链表，筛选五条产业链 ID。
2. 构建每条产业链的上中下游节点树。
3. 对每条产业链生成关键词和上市公司篮子。
4. 接入实时行情：
   - 股票实时行情
   - 概念/行业板块行情
   - 指数行情
   - 相关商品期货行情
5. 接入非实时基本面：
   - 国家统计局月度数据
   - 海关月度数据
   - 交易所公告/巨潮公告
   - 政策文件
   - 招投标
6. 按 7 个一级指标打分。
7. 输出五条产业链横向对比表。

横向对比表建议字段：

| 产业链 | 总分 | 等级 | 供需 | 传导 | 价值 | 协调 | 政策技术 | 实时 | 断链韧性 | 置信度 | 主要驱动 | 主要风险 |
| ------ | ---: | ---- | ---: | ---: | ---: | ---: | -------: | ---: | -------: | ------ | -------- | -------- |
