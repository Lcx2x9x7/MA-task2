# 新能源汽车产业链 ETF 评价指标说明

## 评价目标

当前 Evaluator 评价的是新能源汽车产业链景气度。系统使用四个固定 ETF 代表产业链的全链、上游、中游和下游环节，并读取本地预爬取的政策/新闻文本库，计算三个核心指标：

```text
产业趋势
传导效率
政策支持
```

综合分满分为 100 分。

```text
综合分 =
  0.50 * 产业趋势
+ 0.25 * 传导效率
+ 0.25 * 政策支持
```

权重分配原则：

- 产业趋势权重为 50%，因为景气度评价首先要判断市场方向和强弱；如果价格趋势本身偏弱，即使传导和政策较好，也不能直接判断为高景气。
- 传导效率权重为 25%，因为它体现产业链分析特征，能判断趋势是否从单点扩散到链条，但它是对趋势可靠性的增强项，不应高于趋势本身。
- 政策支持权重为 25%，因为政策、标准、补贴、充电基础设施和监管方向决定产业链中长期落地环境，但政策信号需要通过市场和企业经营兑现，因此权重不高于产业趋势。
- 所有权重采用可解释的规则权重，当前 MVP 不使用机器学习拟合，避免样本不足时产生不可解释的权重。

## 指标一：产业趋势

### 为什么使用

产业趋势用于回答“新能源汽车产业链当前是走强、走弱还是震荡”。景气度评价首先需要判断方向，而 ETF 价格序列能实时反映市场对对应环节的预期变化。

### 计算方法

先对每只 ETF 计算一个趋势分，再按产业链权重加权。

单只 ETF 趋势分满分 100 分：

```text
单只 ETF 趋势分 =
  0.25 * 短期动量
+ 0.35 * 中期趋势
+ 0.25 * 均线结构
+ 0.15 * 成交量确认
```

| 因子       | 权重 | 评判标准                                                                                 | 使用理由                                             |
| ---------- | ---: | ---------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| 短期动量   |  25% | `50 + 近5日收益率 * 4`，限制在 0-100                                                   | 识别最近一周市场预期是否快速改善或恶化               |
| 中期趋势   |  35% | `50 + 近20日收益率 * 2.5`，限制在 0-100                                                | 20 个交易日更接近月度趋势，不容易被单日波动主导      |
| 均线结构   |  25% | 最新价站上 MA5 得 20 分，站上 MA20 得 30 分，MA5 >= MA20 得 25 分，MA20 >= MA60 得 25 分 | 趋势排列能判断短中长期价格结构是否一致               |
| 成交量确认 |  15% | `50 + (20日量比 - 1) * 35`，限制在 20-100；若放量下跌则扣分                            | 趋势需要成交量验证，放量上涨更可靠，放量下跌提示风险 |

趋势因子权重理由：

- 中期趋势 35%：20 日收益更接近月度产业预期，抗噪声能力强，是趋势判断的主因子。
- 短期动量 25%：5 日收益能捕捉实时变化，但容易受短线波动影响，因此低于中期趋势。
- 均线结构 25%：均线能识别趋势结构是否一致，但属于价格派生指标，权重不高于收益率本身。
- 成交量确认 15%：成交量用于验证趋势可靠性，但量能可能受换手、套利和市场情绪影响，因此作为辅助确认项。

四只 ETF 加权后的产业趋势：

```text
产业趋势 =
  0.30 * 515030 全链总锚趋势分
+ 0.20 * 159671 上游资源趋势分
+ 0.30 * 159755 中游电池趋势分
+ 0.20 * 159565 下游零部件趋势分
```

### 评判标准

|  分数 | 判断         |
| ----: | ------------ |
| >= 85 | 趋势强劲     |
| 70-85 | 趋势偏强     |
| 55-70 | 趋势中性偏强 |
| 40-55 | 趋势中性偏弱 |
|  < 40 | 趋势偏弱     |

## 指标二：传导效率

### 为什么使用

产业链分析不能只看某一个环节是否上涨，还要看信号是否沿上中下游扩散。传导效率用于回答“产业链内部是否形成顺畅联动”。如果只有单一 ETF 走强，而上游、中游、下游没有同步或滞后响应，则产业链景气的可靠性较低。

### 计算方法

传导链路固定为：

```text
159671 上游资源
-> 159755 中游电池
-> 159565 下游零部件
-> 515030 全链总锚
```

先对四只 ETF 的共同交易日计算日收益率。每条链路计算 0、1、2 日滞后相关，选择得分最高的滞后关系作为该链路的有效传导。

单条链路分满分 100 分：

```text
单条链路分 =
  0.75 * 最优滞后相关得分
+ 0.25 * 滞后速度得分
```

其中：

```text
最优滞后相关得分 = 50 + 相关系数 * 50，限制在 0-100
滞后速度得分：0 日 = 100，1 日 = 80，2 日 = 65
```

总传导效率：

```text
传导效率 =
  0.70 * 三条链路平均分
+ 0.30 * 三条链路近20日平均同向率
```

传导效率权重理由：

- 单条链路中，最优滞后相关得分权重 75%，因为传导效率的核心是上游、中游、下游收益率之间是否存在稳定联动。
- 滞后速度得分权重 25%，因为传导越快越好，但速度必须建立在相关性存在的基础上，不能让“快但弱相关”的链路获得过高分。
- 总传导效率中，三条链路平均分权重 70%，用于衡量产业链结构性传导关系。
- 近 20 日同向率权重 30%，用于校验近期是否同步，防止历史相关性较高但近期明显分化时被误判为高传导。

### 评判标准

|  分数 | 判断       |
| ----: | ---------- |
| >= 85 | 传导顺畅   |
| 70-85 | 传导较顺畅 |
| 55-70 | 传导一般   |
| 40-55 | 传导偏弱   |
|  < 40 | 传导不畅   |

## 指标三：政策支持

### 为什么使用

新能源汽车产业链受政策、标准、基础设施和消费刺激影响明显。政策支持用于回答“当前政策环境是否有利于产业链中长期落地”。它能补充 ETF 行情中看不到的监管导向、补贴延续、充电网络建设、智能网联标准和绿色低碳约束等信息。

### 数据来源

读取本地预爬取文本库：

```text
data/新能源汽车产业链/*.txt
```

文本中包含标题、来源、日期、URL、产业链标签和正文。该数据不是实时接口，而是提前爬取并清洗后的外部政策/新闻文本。

### 计算方法

政策支持分满分 100 分，采用可解释关键词规则：

```text
政策支持 =
  0.55 * 相关文本平均分
+ 0.15 * 政策覆盖度
+ 0.15 * 近期政策密度
+ 0.10 * 权威来源占比
- 0.05 * 监管约束风险
```

其中单篇文本先计算：

```text
单篇政策文本分 =
  0.35 * 产业链相关性
+ 0.35 * 支持强度
+ 0.12 * 来源权威性
+ 0.08 * 近期性
- 0.10 * 监管约束强度
```

这样做的原因是：政策文本多不等于政策支持强，必须先判断文本是否真正指向新能源汽车、动力电池、充电基础设施、智能网联等产业链环节；同时，安全、监管、准入、强制性标准等词不再加分，而是作为合规约束和短期成本压力扣分。

主要识别信号：

| 信号       | 示例关键词                                                               | 作用                                                     |
| ---------- | ------------------------------------------------------------------------ | -------------------------------------------------------- |
| 支持性政策 | 支持、促进、推动、加快、鼓励、补贴、以旧换新、充电基础设施、车网互动     | 判断政策是否在扩大需求、完善基础设施或降低产业落地成本   |
| 直接相关   | 新能源汽车、动力电池、充电基础设施、车网互动、智能网联、汽车消费、纯电动 | 判断政策文本是否直接指向新能源汽车产业链                 |
| 辅助相关   | 绿色低碳、双碳、可再生能源、新型电力系统、循环经济、储能                 | 作为辅助信号，不能单独把泛绿色政策判定为强支持           |
| 权威来源   | 国家发展改革委、工信部、国家能源局、市场监管等                           | 判断政策信号是否来自高权威部门                           |
| 监管约束   | 安全、监管、准入、强制性、风险、合规、主体责任                           | 作为扣分项，识别可能提高短期合规成本或限制无序扩张的风险 |

### 评判标准

|  分数 | 判断           |
| ----: | -------------- |
| >= 85 | 政策强支持     |
| 70-85 | 政策较支持     |
| 55-70 | 政策中性偏支持 |
| 40-55 | 政策中性偏弱   |
|  < 40 | 政策支持不足   |

## 底线说明

- 当前指标使用 ETF 行情和预爬取政策文本，反映市场价格视角下的产业链趋势、环节联动和政策环境。
- ETF 行情不能直接等同于真实供需、产能、库存、订单或利润；政策文本规则评分也不能替代正式政策效力审查。
- 当前版本不构成投资建议。
- 如果用于正式产业判断，应进一步叠加销量、排产、库存、原材料价格、企业财报、政策原文效力级别和实施细则等基本面数据。
