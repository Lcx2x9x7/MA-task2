## 指标一：产业趋势

作用：判断新能源汽车产业链当前处于走强、走弱还是震荡。

每只 ETF 先计算一个趋势分：

| 因子 | 权重 | 量化方法 |
|---|---:|---|
| 短期动量 | 25% | `50 + 近5日收益率 * 4`，限制在 0-100 |
| 中期趋势 | 35% | `50 + 近20日收益率 * 2.5`，限制在 0-100 |
| 均线结构 | 25% | 最新价站上 MA5、MA20，且 MA5/MA20/MA60 趋势排列越好得分越高 |
| 成交量确认 | 15% | 最新成交量相对过去 20 日均量越高，趋势确认度越高；放量下跌会扣分 |

四只 ETF 再按产业链重要性加权：

```text
产业趋势 =
  0.30 * 515030 全链总锚趋势分
+ 0.20 * 159671 上游资源趋势分
+ 0.30 * 159755 中游电池趋势分
+ 0.20 * 159565 下游零部件趋势分
```

权重理由：

- 全链总锚和中游电池各 30%，因为前者代表产业链整体方向，后者代表新能源汽车产业链核心价值环节。
- 上游资源和下游零部件各 20%，因为它们分别反映成本端和扩散端，但单独代表性弱于全链和电池。
- 单 ETF 趋势因子中，20 日趋势权重最高，因为产业趋势不应被单日或单周波动主导。

## 指标二：传导效率

作用：判断行情信号是否能沿产业链从上游、中游、下游传递到全链总锚。

传导链路：

```text
159671 上游资源
-> 159755 中游电池
-> 159565 下游零部件
-> 515030 全链总锚
```

计算方法：

1. 对四只 ETF 的共同交易日计算日收益率。
2. 对每条链路计算 0、1、2 日滞后相关系数。
3. 相关系数越高、最优滞后越短，链路传导越快。
4. 加入近 20 日同向率，避免历史相关较高但近期明显分化时被误判为高传导。

```text
单条链路分 =
  0.75 * 最优滞后相关得分
+ 0.25 * 滞后速度得分

传导效率 =
  0.70 * 三条链路平均分
+ 0.30 * 三条链路近20日平均同向率
```

## 综合分

```text
综合分 =
  0.50 * 产业趋势
+ 0.25 * 传导效率
+ 0.25 * 政策支持
```

综合权重理由：

- 产业趋势占 50%，因为景气度首先取决于方向和强弱。
- 传导效率占 25%，因为它体现产业链联动质量，但如果趋势本身偏弱，高传导也只能说明同步走弱，不能代表高景气。
- 政策支持占 25%，因为政策、标准、补贴和基础设施建设会影响产业链中长期落地，但政策信号不应高于市场趋势本身。
- 当前权重是专家规则权重，用于 MVP 的可解释评分，不是基于历史样本训练得到的统计权重。

## 指标三：政策支持

作用：判断新能源汽车产业链是否受到政策、标准、基础设施、消费促进、税费减免和金融配套等外部环境支持。

数据来源：

```text
data/新能源汽车产业链/*.txt
```

计算方法：

1. 读取本地预爬取政策/新闻文本。
2. 识别支持性关键词，例如“支持、促进、推动、加快、补贴、金融、专项债、减免、充电基础设施、车网互动”等。
3. 识别战略相关词，例如“新能源汽车、动力电池、智能网联、绿色低碳、双碳、新型电力系统”等。
4. 识别监管约束词，例如“安全、监管、准入、标准、强制性、合规”等。
5. 综合政策数量、近期政策、权威来源和关键词密度，得到 0-100 的政策支持分。

## 为什么选择这三个指标

- 产业趋势是景气度评价的基础，回答“产业链是不是在变强”。
- 传导效率体现产业链分析特征，回答“这种变强是不是从单点扩散为链条联动”。
- 政策支持补充中长期落地环境，回答“政策、标准、基础设施和监管方向是否支持产业链继续发展”。
- 三个指标分别覆盖市场趋势、链条联动和政策环境，适合当前实时行情加离线政策文本的 MVP。

## 边界

- ETF 行情代表市场价格视角，不直接等同于真实经营景气。
- 如果要进一步提高可靠性，需要叠加销量、排产、价格、库存、财报和政策文本。
- 当前版本不构成投资建议。
